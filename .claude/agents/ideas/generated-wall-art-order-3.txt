Series: generated-wall-art.txt. Consumes order 1's manifest (R9 of order 1) and order 2's strata model.
Read docs/wall-renderer-guide.txt and art-direction sections 4-5 + RENDER RESOLUTION TIERS first.


OVERVIEW
--------
Make WallRenderer draw generated walls the way the enemy layer draws generated creatures: textures from
a per-floor ATLAS described by a manifest, the emissive layer drawn ungraded over the graded base, and a
little life - all without giving back any of render-performance-full-hd's speed. Then switch stratum A's
registry rows from placeholders to the generated art, so every region-A floor shows the new walls.


SCOPE
-----
IN
  - render/tilesetgfx: WallAtlas (parsed <stratum>.walls.json + its two textures; Disposable, per floor,
    loaded in buildLevelDependentResources beside EnvironmentTextureSet, disposed with it) and a
    "generated" sprite source: a registered sprite id may resolve to an ATLAS REGION instead of a
    stand-alone Texture (one row in the existing registry idiom - never a switch).
  - WallRenderer:
      * column texture lookup returns (texture, srcX, srcY, size) for atlas sprites; pre-resolved per
        level into char-indexed arrays exactly like today (no map lookup per column);
      * BASE VARIANTS: a BASE-role symbol has up to 3 regions; the column picks one by
        GameMath.wallVariantIndex(tileColumn, tileRow, side, floorSeed, variantCount) - stable per face;
      * GLOW PASS: after the base pass, for columns whose sprite has a glow region, draw the glow
        column (same stripe geometry) with NORMAL blend, ungraded, fogged only by
        ENEMY-style alpha fade with distance (new WALL_GLOW_FADE_START/MIN_ALPHA constants);
      * ANIMATION: a sprite with glow frames picks the frame from the world clock (frame durations from
        the manifest); per-face phase offset from the same hash so lamps do not flicker in sync;
      * LOD: the column picks mip 0/1/2 by its on-screen texels per column (GameMath.wallMipLevel:
        texture texels covered by one screen column = 256 / lineWidthInColumns... see TECHNICAL NOTES),
        killing distant shimmer;
      * the opaque fast path (R16) and equal-neighbour column merge (R18) still apply: the atlas is
        opaque; merge compares (texture, srcX, srcY, mip) instead of (texture, srcX).
  - Stratum A rows in WallStrata point at wall_a_* ids; their sprites are registered as atlas sprites.
  - art-direction.txt section 5 gains "wall emissives" in the exemption list; a new subsection
    "WALLS" (atlas, variants, glow, LOD); wall-renderer-guide.txt updated; environment-tileset-system
    section 15 updated.
OUT
  - Doors and columns (order 8) - they keep their current textures and paths.
  - Strata B-E art (4-7); they keep placeholders.
  - Any shader (V2) - SpriteBatch only.


RULES
-----
  R1  No allocation in render(); all atlas lookups resolved at level load.
  R2  One wall-atlas texture bind for the base pass and one for the glow pass per frame (plus the
      untouched door/column textures).
  R3  The glow column is exempt from the mood grade and the red-alert dampen (V6); BLACKOUT dims it
      by the existing BLACKOUT factor only (a lamp in a blackout reads as a lamp, slightly dimmed).
  R4  Variant choice is a pure function of the face, so the same wall face always shows the same
      variant (no popping when turning) and two runs of the same seed look identical.
  R5  Mip choice never flickers between frames for a static view (pure function of distance).
  R6  Full HD and HD tiers both supported; the mip formula uses the tier's column width.


TECHNICAL NOTES
---------------
  - Texels per screen column at a face: the stripe of lineHeight pixels shows 256 texel rows, and one
    ray column covers (columnWidth / lineWidthOfTile) of the texture's 256 columns. Use the vertical
    term: texelsPerPixel = 256 / lineHeight; mip = clamp(floor(log2(max(1, texelsPerPixel * BIAS))), 0, 2).
    GameMath.wallMipLevel with the mandatory comment block. (math-expert)
  - GameMath.wallVariantIndex: splitMix64 of (tileColumn, tileRow, side, floorSeed) mod count.
  - Sampling an atlas sub-rect per column: batch.draw(texture, x, y, w, h, srcX + texColumnAtMip,
    srcY, 1, sizeAtMip, false, false) - srcY is the region's top row (LibGDX Y-up rule unchanged).
  - Padding: order 1 duplicates edge texels into the 2 px padding, so Nearest sampling at u=0 / u=1
    never bleeds a neighbour.
  - Worker threads: the pre-resolved arrays are immutable per level (same publication contract as
    today's levelWallTextures).
  - Perf: measure base + glow pass with run-game --probe cpu on a region-A floor vs the placeholder
    build of order 2, same session, interleaved A/B twice (run-game section 4).

EDGE CASES
----------
  - A manifest that fails to load: log it, the stratum falls back to its placeholder rows for that
    floor (never a crash, never a missing wall) - mirrors EnemyAtlasCache's rule.
  - A sprite with no glow region: no glow column drawn.
  - Floor transition mid-flicker: the clock is world time; the new floor simply starts its own phase.
  - App pause / GL context loss: the atlas reloads with the floor's other textures.


ACCEPTANCE CRITERIA
-------------------
  A1  On a generated region-A floor (run-game, cool_steel), the walls are the order-1 kit: three base
      variants visible along a corridor, structure rhythm, lit strip lamps, one flickering lamp.
  A2  Lamps keep their colour when the mood is forced to amber_hot (glow ungraded) while the panels
      take the amber grade.
  A3  At 8+ tiles a long wall shows no moire/shimmer when the player turns (capture a turn burst).
  A4  run-game --probe cpu: wall base + glow pass time within +10% of order 2's placeholder walls on
      the same floor, same session (numbers recorded in the checkpoint file); draw calls do not grow
      per wall sprite (one atlas).
  A5  Regions B-E floors still render (placeholders), the start room renders, hand levels render.
  A6  20 floor transitions: texture count stable (no leak) - the probe's texture/bind readout or a log.
  A7  Docs updated (art-direction WALLS + V6 list, wall-renderer-guide, tileset section 15).
