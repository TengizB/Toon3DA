Part of the generated-enemy-art series. Requires orders 1-8 (every EnemyType has a generated, animated
creature). Read generated-enemy-art.txt and docs/sprite-art-creation-guide.txt before starting.


OVERVIEW
--------
Finishes the series by deleting everything the old enemies needed and nothing else does: the image-model
textures, the 2x2 sheet slicing, the per-texture fields, the boss placeholder mapping, the alpha-cut
conditioning that cleaned image-model halos, the lunge-scale fake, and the legacy body-draw path. After
this order the new enemy visual layer is the only one, and the game ships only generated enemy art.


SCOPE
-----
IN
  - Delete the nine old PNGs (enemy_sheet_blight, enemy_sheet_infernal, enemy_sheet_elemental_golems,
    enemy_corruptor, enemy_vortex_eye, enemy_ghoul, enemy_crawler, enemy_revenant, enemy_boss_overseer),
    their EnemyConstants paths and fallback colours, EnemyRenderer's per-texture fields, buildTextureRegions'
    quadrant code and the boss placeholder mapping.
  - Delete the legacy body-draw path in EnemyRenderer and the lunge scale/drop constants it used.
  - EnemySpriteSheets: remove the alpha-cut conditioning pass (every input is binary by construction) or
    fold the class into EnemyAtlasCache - whichever leaves less code.
  - Consider folding the renderer's golem overlays (shard ring, crust plates, state tints) into the new
    layer where an animated clip now does the job better; keep any that still read best as overlays.
    Each change is named in the IMPLEMENTATION NOTE.
  - A load-time error log naming any EnemyType without an EnemyVisualRegistry row (no type may be invisible).
  - Final performance pass (G13): frame time and texture memory on the busiest floor of each region and on
    each boss floor, compared with the pre-series numbers recorded in order 2.
  - Docs: guide (all [PLANNED] markers gone), art-direction section 9 rewritten and 16 completed,
    docs/enemy-system.txt, CLAUDE.md (render/ structure: the enemyvisual package as THE enemy renderer,
    EnemySpriteSheets entry updated), the series master marked complete.

OUT
  - New creatures, new clips, new effects. Directional sprites (series AS2).
