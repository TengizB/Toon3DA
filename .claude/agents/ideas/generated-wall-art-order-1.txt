THE WALL KNOWLEDGE DOCUMENT IS docs/wall-art-creation-guide.txt - how walls, doors, columns, floors
and ceilings must be created: the format, tiling, trim lines, the region set, the placement rules, the
design and repetition rules, materials, glow, output, verification, every lesson and every piece of owner
feedback. Read it before any work in this order; update it in the same commit as any change to what it
describes. The enemy-art kit's technique (docs/sprite-art-creation-guide.txt sections 1-4) is the tool.

Series: generated-wall-art.txt (read it first: the region-set model, the symbol table, rules W1-W12,
decisions). OFFLINE ONLY: no Java.


OVERVIEW
--------
Turn the approved prototype script (.claude/skills/enemy-art/walls_prototype.py) into the real builder,
walls.py, and make the COMPLETE REGION A SET - the Outer Facility / Habitation Rings: hall base +
variety, the six room-family sets, the signature set, doors, columns, floor and ceiling. The output is
exactly what order 2's runtime loads: one atlas + one glow atlas + a manifest per region, plus the
region's two surface PNGs. Nothing is wired here; the gate is the owner's approval of set A.

RULES
-----
  R1  WALL FACE 256x256 RGB, opaque, row 0 = ceiling line, row 255 = floor line. Surface 64x64, opaque.
  R2  TILING: walls stamped at x-256, x, x+256 and cropped; surfaces on a 3x3 canvas. A strip of every
      hall wall beside every other shows no seam; each room set's strip likewise; trim lines meet.
  R3  TRIM LINES (region A): cornice 0-30, cable tray 24-33, panel field 40-196, bump rail 205, kick
      plate 214-255. Every A wall honours them (a room wall may change what is BETWEEN the lines).
  R4  VARIANTS: hall BASE x3 and each room BASE x2 are one design with seeded differences (a dent, a
      different vent, a scuff, a stencil number) - unnoticeable at 4 tiles, noticed up close.
  R5  ROOM SETS READ AS ROOMS (W6): at 4 tiles a player can tell hall from medical from security etc. by
      shape and material (silhouette of fixtures, panel division, surface), checked on the contact sheet
      at 1x and in-engine.
  R6  GLOW: emissive pixels to the glow atlas at the same rect; <= ~6% of a wall's pixels; a wall without
      emissives has glowRect null.
  R7  ANIMATION: the LIGHT face carries 4 FLICKER glow frames (1.0, 0.25, 1.0, 0.0), 0.08-0.4 s, flagged
      "animate": "some" in the manifest - the runtime (order 2) plays them on a seeded ~1 in 6 LIGHT faces
      (a failing tube) and shows frame 0 everywhere else.
  R8  MIPS: 256 / 128 / 64, 2x2 box filter, packed in the same atlas; surfaces get no mips (the floor
      pipeline builds its own from the 64x64).
  R9  ATLAS <= 2048x2048, 2 px padding filled with duplicated edge texels; packing order = manifest order.
  R10 KEYCARD DOORS: the door body is region A's; the lock panel and a frame stripe carry the keycard
      colour (exact ItemConstants / CombatPalette keycard values), emissive, so no mood shifts them.
  R11 MANIFEST <region>.walls.json, version 1:
        { "version": 1, "region": "outer_facility", "size": 256, "mips": 3,
          "trim": {...}, "breach": {"base": 0.0, "step": 0.03},
          "walls":   [ {"id": "wall_a_hall_base_0", "group": "HALL", "slot": "BASE", "variant": 0,
                        "rect": [x,y], "mipRects": [[x,y],[x,y]], "glowRect": [x,y] | null,
                        "glowFrames": [{"rect": [x,y], "duration": 0.08}, ...] | null,
                        "animate": "all" | "some" | null }, ... ],
          "doors":   [ {"id": "door_a_plain" | "door_a_red" | "door_a_yellow" | "door_a_blue", ...same fields} ],
          "columns": [ {"id": "column_a_round" | "column_a_square", ...same fields} ],
          "surfaces": {"floor": "outer_facility.floor.png", "ceiling": "outer_facility.ceiling.png"} }
      group in HALL / MEDICAL / SECURITY / CONTAINMENT / MACHINERY / RESEARCH / STORAGE / SIGNATURE;
      slot in BASE / ACCENT for room groups, BASE / STRUCTURE / LIGHT / SERVICE / VENT / MARKER / BREACH
      for HALL. Ids are STABLE: wall_<region letter>_<group>_<slot>[_<variant>], never renamed.
  R12 Determinism: walls.py twice -> byte-identical files; bestiary.py output unchanged.


VISUAL DESIGN - REGION A, THE OUTER FACILITY / HABITATION RINGS (mood cool_steel)
---------------------------------------------------------------------------------
An evacuated company town. Everything is Organization issue and recently lived in. The wrongness is
small: notices torn off, name plates scratched out, a hairline seep at a seam on the deep floors.
Value note from the captures: the livery panels read slightly too bright and flat at range - drop them
one ramp step and add grime at the panel foot.

HALL
  BASE x3       the approved prototype: two chamfered livery panels, vent inset, bump rail, kick plate.
  STRUCTURE     a gunmetal pilaster with a ring serial stencil, the rail running behind it.
  LIGHT         a recessed cyan strip lamp in the panel field (some flicker at runtime - R7).
  SERVICE       an exposed riser pipe pair through a panel cut-out.
  VENT          a full-height access hatch with a grille and a pull handle.
  MARKER        an evacuation board: empty frames, torn notices, an arrow stencil, "R1".
  BREACH        the base panel with a cracked seam weeping a thin ichor line (emissive, 1-2 px).
MEDICAL         clean white livery, rounded corners, a cyan "care" band at rail height (NO cross),
                BASE x2 + ACCENT = a wall dispenser unit with a sealed scrub hatch.
SECURITY        dark gunmetal plating, a chevron-grooved lower half (carved, not painted yellow),
                BASE x2 + ACCENT = a weapons locker / gun rack niche behind a mesh.
CONTAINMENT     heavy insulated panels with frost-pale seams (capsule material),
                BASE x2 + ACCENT = a sealed porthole hatch with frosted glass.
MACHINERY       breaker cabinets and conduit bundles, darkmetal,
                BASE x2 + ACCENT = a big breaker panel with a cyan status lamp and a lever.
RESEARCH        dark panels with thin cyan data seams,
                BASE x2 + ACCENT = a wall terminal (dark bezel, a few cyan text lines, keys).
STORAGE         corrugated steel shutters and stacked crate slots,
                BASE x2 + ACCENT = a roll-up shutter half open (dark gap, a crate edge).
SIGNATURE       CREW QUARTERS of the company town - the region's special-room look:
                BASE x2 = rows of crew lockers, name plates scratched off;
                ACCENT = one locker door ajar, dark inside, a scarf left on its hook (no figure - W14).
DOORS           a painted livery sliding door with a porthole and rubber seal; keycard doors add the
                coloured lock panel + frame stripe (R10).
COLUMNS         round: a painted steel pillar with the bump rail ring; square: a boxed cable riser.
FLOOR           deck plates with a worn rubber runner; CEILING: cable trays and strip-lamp housings
                (no glow - the pipeline has no surface emissives). Value bands: floor 0.10-0.24,
                ceiling 0.06-0.18 average luminance (art-direction section 6).
Story details (W8): ring serials, the evacuation board, the scratched name plates, the left scarf.

    group, slot, variant, builder, frames?)], doors=[...], columns=[...], surfaces=(floor_fn,

EDGE CASES
----------
  - A stencil glyph missing: add it to STENCIL_FONT (appended), never drop the stencil.
  - A shape beyond one tile of the face on the 3-tile canvas: the bake warns; keep shapes within it.
