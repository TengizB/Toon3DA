OVERVIEW
--------
The single engine order of the series. It replaces how walls are CHOSEN (the level layer), how they are
DRAWN (the wall runtime), and DELETES the old wall layer - all in one order, so the game goes from "any
wall on any floor" straight to "every floor built from its region's set" with no period of old walls.
Regions whose own set has not shipped (B-E until orders 3-4) borrow set A (D8).

Three parts, each a group of checkpoints:
  PART 1 - CHOOSING: region sets, room families, the slot table, the placement rules, every generator
           through one finisher. (headless: tileset, level, route, world)
  PART 2 - DRAWING: the region atlas runtime - walls, variants, glow, animation, LOD, doors, columns,
           floor/ceiling from the set. (render)
  PART 3 - DELETING: the whole old wall/door/column/floor layer. (both)


SCOPE
-----
IN - PART 1 (choosing)
  - tileset: WallGroup (HALL MEDICAL SECURITY CONTAINMENT MACHINERY RESEARCH STORAGE SIGNATURE) and
    WallSlot (BASE STRUCTURE LIGHT SERVICE VENT MARKER BREACH ACCENT) enums with per-constant data;
    RegionWallSet (immutable: id, per (group, slot) the ordered sprite ids incl. variants, door ids,
    column ids, surface ids, breachBase/breachStep); RegionWallSetRegistry + RegionWallSets.bootstrap()
    reading the shipped manifests' ids (set A real; B-E rows that ALIAS set A until orders 3-4 - an
    alias is one registry row, "borrows": "outer_facility").
  - The SYMBOL -> (group, slot) table (master) in TilesetConstants; a RegionPaletteBuilder:
    (region set) -> LevelPalette binding every wall symbol to its slot's sprite (variant 0; variants are
    the renderer's), 'P' to the set's columns.
  - route: RegionAmbience.wallPalette + RouteMapConstants.REGION_*_WALL_PALETTE deleted; replaced by
    wallSetId per region; World resolves the floor's set like the lighting mood (fallback
    outer_facility + one log line); startup fails loud if a region names an unregistered set.
  - level: LevelGenConfig gains wallSetId + floorIndexInRegion (set by World with its other per-floor
    fields); a `LevelFinisher` that EVERY generator's final Level goes through (dungeon, corridor,
    cavern, boss arena, med bay, event, gate airlock, start room): stamp room-family walls (P2/P3),
    run the hall placement (P4-P8), build the region palette.
  - level: each RoomBlueprint registration names its WallGroup (master's family table); each special
    generator names its group (MED_BAY -> MEDICAL, gate -> SECURITY, event + boss -> SIGNATURE). The
    per-room wall-theming passes in LevelGenerator / LinearCorridorGenerator / CavernGenerator that
    stamp old-meaning chars ('Z' cryo, 'M' medical ...) and the cavern biome char lists are REPLACED by
    the finisher's family stamping - no generator writes a wall picture symbol again.
  - The placement rules P1-P8 with constants WALL_SET_* in LevelGenConstants; their own RNG stream
    (GameMath.wallSetSeed: the paletteSymbolSeed derivation with a new salt) so the generator's random
    sequence is untouched.
IN - PART 2 (drawing)
  - render/tilesetgfx: RegionWallAtlas (parses <region>.walls.json, loads atlas + glow textures and the
    two surface PNGs; Disposable; built in World.buildLevelDependentResources for the floor's set,
    disposed with the floor - replaces EnvironmentTextureSet's wall/door/column role).
  - WallRenderer: per level, pre-resolve char -> atlas region arrays (no map lookup per column, as
    today); BASE VARIANTS per face (GameMath.wallVariantIndex); GLOW pass after the base pass (NORMAL
    blend, ungraded, BLACKOUT-dimmed, distance alpha fade WALL_GLOW_FADE_START_TILES 10 /
    WALL_GLOW_MIN_ALPHA 0.6); glow FRAME animation from the world clock with per-face phase ("all" =
    every face of that sprite, "some" = a seeded ~1 in 6); distance LOD mip 0/1/2 (GameMath.wallMipLevel);
    the opaque fast path (R16) and equal-column merge (R18) kept, merge key (srcX, srcY, mip).
  - Doors (d R Y B) and columns (P) drawn from the same atlas: the door slide animation and keycard
    logic unchanged, only their texture source.
  - Floor / ceiling: SurfaceMaterialRegistry loads the region's floor/ceiling PNGs (converted once to its
    packed int[] layout: row 0 = south edge, column 0 = west) instead of generating the ten procedural
    materials; mood bindings point at the region set's surfaces; FloorCeilingRenderer's pipeline,
    mips, bands and batching are unchanged.
  - art-direction: V6 exemption list gains "wall emissives"; new section "WALLS" (sets, atlas,
    variants, glow, LOD); section 6 rewritten for surfaces from region sets.
IN - PART 3 (deleting) - the old layer goes completely (W12)
  - WallRenderer: every generate*WallTexture, generateProceduralDoorTexture, loadOrGenerateDoorTexture,
    generateColumn*Texture, loadWallTexture's JPEG path, registerTextureGenerators' wall/column rows.
  - Files: assets/textures/lab/lab_wall_*.jpg, lab_door_*.jpg, assets/textures/wall.png (grep first:
    barrel_radioactive.png is a PROP and stays).
  - tileset: every old wall_* / column_* sprite id and registration, VARIETY_ONLY_SPRITE_IDS' wall and

  - GameBalance PALETTE_* knobs used only by the wall grab; RenderConstants *_WALL_TEXTURE_SIZE, door
    and column constants and colour tables used only by deleted generators; the ten procedural
    SurfaceMaterials generators.
  - Existing tests encoding the old catalog/allocator are UPDATED to the new model (W10): the guard
    "every wall symbol resolves to a registered sprite" stays, now per region set.
  - Docs in the same commits: environment-tileset-system.txt (new section 15 "REGION WALL SETS",
    sections 1/2/4/6/7/8/9 marked superseded for walls with a pointer), tile-symbols.txt (wall symbols

RULES
-----
  R1  2D GAME UNTOUCHED (W7): for 200 seeds x every generator x depths 1-25, the walkable mask and every
      FIXED symbol (doors, spawns, pickups, props, hazards, start, exit) are identical to the build
      before this order - checked by a throwaway script whose output is pasted in the checkpoint file.
  R2  Determinism: same seed + depth -> byte-identical grid, palette and variant choices.
  R3  Every wall on a floor resolves to the floor's region set (or its alias) - never another region,
      never null. A slot a set lacks falls back by WallSlot.fallback (data): ACCENT -> BASE,
      BREACH -> BASE, others -> HALL BASE.
  R4  No allocation in render(); one atlas bind for walls+doors+columns per pass; one for glow.
  R5  Glow is exempt from the grade and the red-alert dampen; BLACKOUT dims it by its factor only.
  R6  Variant, animation phase and mip are pure functions of (face, floor seed, distance, clock) -
      no popping when turning, identical across runs of a seed.
  R7  A manifest that fails to load -> log + the floor uses set A (never a crash, never a missing wall).


TECHNICAL NOTES
---------------
  - Flow: World -> LevelGenConfig(wallSetId, floorIndexInRegion) -> generator -> LevelFinisher.finish(
    grid, rooms+groups, spawns, ..., config) -> family stamping -> placement -> RegionPaletteBuilder ->
    new Level(...). Rooms reach the finisher with their WallGroup (the dungeon generator already has its
    Room list + blueprint ids; the special generators pass one group for the whole floor).
  - "Exposed" = a wall with a walkable 4-neighbour (Level predicates). A room's perimeter = the
    exposed walls whose walkable neighbour is inside the room's interior rectangle.
  - Straight runs: scan rows and columns for exposed faces sharing the same open side.
  - GameMath (math-expert, mandatory comment blocks): wallSetSeed, wallVariantIndex (splitMix64 of
    column, row, side, seed mod count), wallMipLevel (texelsPerPixel = 256 / lineHeight; mip =
    clamp(floor(log2(max(1, texelsPerPixel x WALL_MIP_BIAS))), 0, 2)).
  - Atlas column draw: batch.draw(texture, x, y, w, h, srcX + texColumnAtMip, srcY, 1, sizeAtMip, false,
    false) - srcY = the region's top row (the LibGDX Y-up rule is unchanged).
  - Worker threads read the per-level arrays via the existing publication contract (set before dispatch).
  - Perf: run-game --probe cpu, region-A floor, this order vs the commit before it, interleaved twice.

EDGE CASES
----------
  - Start room / dev runs / hand-made levels: set A, rooms not detected -> walls stay as written, the
    palette maps them through the slot table.
  - Boss arenas: SIGNATURE base; P4/P5 still light them.
  - Tiny rooms (< 3 wide): P2 places at most one ACCENT; P4 skips.
  - A door on a corner: P4 frames only walls in line with it.
  - Floor transition / app pause / GL loss: the atlas reloads with the floor's textures; 20 transitions
    keep a stable texture count.
