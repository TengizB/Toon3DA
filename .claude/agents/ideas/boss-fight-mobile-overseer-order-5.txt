=============================================================================
THE BRIEF
=============================================================================
"boss must be able to heal once during the fight, it flees then heals, boss
restores small amount of hp each turn for 5 turns but if hit stops healing."

Exactly one self-repair per fight. When the Overseer drops below a HP threshold
(and hasn't healed yet), it BREAKS OFF: dashes to a safe spot away from the
player, then REPAIRS a small amount of HP each turn for up to 5 turns. Taking ANY
damage during the repair CANCELS the remaining ticks — and the ability is spent
for the rest of the fight either way. This turns a defensive reset into a player
OBJECTIVE: "cut off its escape and draw blood before it welds itself back up."

=============================================================================
STATE MACHINE (on Boss / a RegenState helper owned by the brain)
=============================================================================
Fields:
  boolean healUsed          = false;  // once-per-fight latch
  boolean healActive        = false;  // currently in the repair chain
  int     healTurnsLeft     = 0;      // remaining repair ticks (starts at 5)

TRIGGER (checked by HunterKillerPattern before normal tactic selection — Order 4
gives HEAL top priority when eligible):
  eligible = (!healUsed)
          && (boss.health / boss.maxHealth <= OVERSEER_HEAL_HP_THRESHOLD)
          && (no danger currently forcing a dodge — don't heal mid-charge)
  When eligible, run the HEAL tactic:

  Step 0  FLEE:  BossMove.dash(chooseFleeTarget(...))  — Order 2's flee helper,
                 preferring a tile with LOS to the player BROKEN by a 'P' column
                 or with a toxic cloud laid between (optionally cast TOXIC first as
                 a cover step). Sets healUsed = true NOW (commit — it can't cancel
                 the flee and re-trigger later). Boss enters a REPAIRING pose.
  Step 1..5 REPAIR: each turn a new BossMove.HEAL step:
                 - restore OVERSEER_HEAL_PER_TURN HP (clamped to maxHealth).
                 - healTurnsLeft--.
                 - the boss HOLDS (planted — it is a punish window! F1). It does
                   NOT attack while repairing — the whole point is you can rush it.
                 - BossHudRenderer shows a "REPAIRING" state + the HP bar visibly
                   ticking up (Order 8).
                 - end the chain when healTurnsLeft == 0.

INTERRUPT (the key fairness mechanic, F4):
  Boss.applyDamage(amount) override: if healActive and amount > 0 →
      healActive = false; healTurnsLeft = 0;  // cancel remaining repair ticks
      (fire an event: BossHudRenderer.showBanner("REPAIR INTERRUPTED"),
       EventTextSystem line; Order 8). The ability stays spent (healUsed already
      true). Then super.applyDamage(amount) as normal.
  So one shell landing on the boss during the weld stops the heal cold. Reaching
  it in time is the player's job; the boss picking a far/covered spot is its
  counter-play. Balanced by geometry + the adds it may leave behind.

=============================================================================
FAIRNESS
=============================================================================
- ONCE per fight (healUsed latch). No repeated stalling.
- Boss does NOT attack while repairing → it is a pure punish window; the tension
  is the RACE to reach it, not surviving its offense during the heal.
- Interruptible by ANY damage (F4). A ranged player interrupts from afar; a melee/
  shotgun player must path past hazards/adds — both viable.
- The flee destination must be REACHABLE by the player within the 5 turns given
  the arena (Order 7 guarantees no fully-walled heal spot — F5). If the boss laid
  toxic to cover the approach, the player still has a path (radius capped, Order 3).
- Telegraph the heal start clearly (banner + pose + distinct aura colour, Order 8)
  so the player immediately understands "go stop it."
