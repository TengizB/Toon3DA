OWNS
====
The FLIP: renderers stop reading the static per-char texture tables and start resolving each
symbol through the level's LevelPalette + EnvironmentTextureSet. After this order, changing a
level's palette VISIBLY changes what its walls/columns/props look like. Because every level still
defaults to the LEGACY palette (order-3), THE GAME LOOKS IDENTICAL after order-7 — variety only
appears once order-8 feeds generated levels a varied palette. order-7 is the "swap the engine under
the hood without changing the ride" step.

THE THREE READS TO REPLACE
==========================
1. WALL texture lookup (WallRenderer):
     BEFORE: texture = wallTextureTable[cellChar]  (static, global).
     AFTER:  spriteId = levelPalette.spriteIdOf(cellChar);
             texture  = environmentTextureSet.textureFor(spriteId);
             width/height likewise from the set.
   Keep the O(1) hot-path shape: at level load, PRE-RESOLVE a per-level char-indexed array
   (char -> Texture) FROM the palette+set, so the render loop still does one array read per column
   (no map lookup per column, preserving the current performance profile and the "no per-frame
   allocation" rule). Rebuild this small array once per level in the per-level setter, not per
   frame. This keeps WallRenderer's parallel worker design intact.
2. COLUMN sprite (WallRenderer column path): resolve 'P' the same way — spriteIdOf('P') -> the
   round OR square column texture. This is the mechanism that lets 'P' render either column per
   level (proven visually in order-8).
3. PROP sprite + height (PropRenderer): the per-char draw dispatch and propHeightMultiplier() read
   the palette's sprite id, then the definition's heightMultiplier (order-1) and the set's texture.
   Replace the height switch with EnvironmentSpriteRegistry.get(spriteId).heightMultiplier().

LEVEL CATEGORY PREDICATES (the careful part)
============================================
Level.isWall()/isColumn()/isPropSolid()/isPropDecal()/isPropOccluder() are called from movement,
collision, LOS, and rendering — not just draw. They must keep answering correctly for BOTH fixed
and flexible symbols. Two-tier resolution:
  * FIXED symbols: keep the existing static char checks (fast, always correct).
  * FLEXIBLE symbols: the category is FIXED per the SymbolBudget (order-2) — a flexible WALL symbol
    is ALWAYS a wall regardless of which wall sprite fills it. So category membership does NOT
    actually depend on the per-level sprite; it depends only on the symbol's FIXED category.
  => Therefore Level's predicates can stay STATIC and correct if they test category membership from
     the SymbolBudget partition (order-2) rather than a hand-maintained char list. RECOMMENDED
     refactor: back isWall()/isColumn()/isPropSolid()/isPropDecal() with the SymbolBudget's
     category tables (fixed + flexible) so there is ONE source of truth for "which category is this
     symbol", and adding a flexible symbol to a category is a data edit, not a predicate edit.
  * DO NOT make these predicates require a LevelPalette argument — they must stay callable from hot
    movement/AI code without a level-render dependency. Category is symbol-intrinsic; only the
    SPRITE needs the palette. This separation is the whole reason category != sprite.
  * isPropOccluder() likewise reads the sprite definition's occluder flag (order-1) via the fixed
    category tables, not a char list.

REMOVE THE OLD TABLES (end state)
=================================
- Delete WallRenderer's constructor-built wallTextureTable/wallWidthTable/wallHeightTable and the
  per-char generate*WallTexture() ownership (those generators now live in the
  TextureGeneratorRegistry, order-6). WallRenderer no longer OWNS wall textures; the
  EnvironmentTextureSet does. Update WallRenderer.dispose() accordingly (it must NOT dispose
  textures it no longer owns — the set owns them).
- Same for PropRenderer's per-char texture ownership.
- This is a net simplification: two big static tables + several switches become one palette read
  path.

TECHNICAL NOTES
===============

  setter running on the GL thread before render().

  the per-level setter, never in render().
