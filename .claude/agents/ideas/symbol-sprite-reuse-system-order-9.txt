      RECIPE A — "Add a new wall/prop/column/decal SPRITE":
        1. Build an EnvironmentSpriteDefinition (id, category, height, occluder, tags) and register
           it in TilesetRegistries.
        2. Register its procedural texture generator in TilesetGfxBootstrap.
        3. (Optional) add theme tags so the allocator uses it coherently.
        => It now appears on generated levels automatically. ZERO edits to LevelGenerator,
           WallRenderer, PropRenderer, or Level. No new symbol needed.
      RECIPE B — "Add a new ROOM":
        1. Write a RoomBlueprint (id, kind, eligible, selectionWeight, symbolDemand, build).
        2. Register it in TilesetRegistries.
        => It competes in generation automatically. ZERO edits to the generator's selection code.
  * The determinism + backward-compat guarantees.
