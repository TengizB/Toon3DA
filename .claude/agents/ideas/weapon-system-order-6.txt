B. Kinetic Slam — ON_HIT (melee only)
──────────────────────────────────────────────
In AbilityResolver.onHit(), add:

    if (weapon.hasAbility(WeaponAbility.KINETIC_SLAM) && weapon.isMelee()) {
        float knockbackChance = weapon.abilityMagnitude(WeaponAbility.KINETIC_SLAM);
        if (rng.nextFloat() <= knockbackChance) {
            // tryPushEnemy pushes the enemy 1 tile in the player's facing direction.
            // It returns true if the push succeeded, false if the tile behind is a wall.
            boolean pushedIntoWall = !enemyManager.tryPushEnemy(hitEnemy,
                                         facingStepColumn, facingStepRow);
            int bonusDamage = pushedIntoWall ? GameBalance.KINETIC_SLAM_WALL_BONUS_DAMAGE : 0;
            if (bonusDamage > 0) hitEnemy.takeDamage(bonusDamage);
            eventTextSystem.showText("SLAM!", EventTextSystem.SLAM_COLOR);
        }
    }

EnemyManager.tryPushEnemy(Enemy enemy, int stepColumn, int stepRow):
  - Target tile = enemy.tileColumn + stepColumn, enemy.tileRow + stepRow.
  - If target tile is not a wall, not occupied by another enemy: move enemy there, return true.
  - If target tile is a wall: enemy stays, return false (wall bonus applies).
  - Reuse existing push logic from Steel Pipe knockback (roguelike_order_9) if present.

The facingStepColumn / facingStepRow parameters must be passed down from
Weapon.fire() → AbilityResolver.onHit(). They are the player's current
facing direction as a unit integer step (e.g., (1,0) facing east).


──────────────────────────────────────────────
C. Cleave — ON_HIT (melee only)
──────────────────────────────────────────────
Cleave damages enemies in the two tiles flanking the primary target:
  - Flanking tiles are 90° left and right of the player's facing direction,
    adjacent to the primary target (not adjacent to the player).

In AbilityResolver.onHit():

    if (weapon.hasAbility(WeaponAbility.CLEAVE) && weapon.isMelee()) {
        float cleaveFraction = weapon.abilityMagnitude(WeaponAbility.CLEAVE);
        int cleaveDamage = Math.max(1, Math.round(damageDealt * cleaveFraction));

        // Left flank = facing rotated 90° CCW; Right flank = 90° CW
        // Left flank tile adjacent to target:
        int leftFlankCol  = hitEnemy.tileColumn + (-facingStepRow);
        int leftFlankRow  = hitEnemy.tileRow    + facingStepColumn;
        int rightFlankCol = hitEnemy.tileColumn + facingStepRow;
        int rightFlankRow = hitEnemy.tileRow    + (-facingStepColumn);

        Enemy leftEnemy  = enemyManager.getEnemyAt(leftFlankCol,  leftFlankRow);
        Enemy rightEnemy = enemyManager.getEnemyAt(rightFlankCol, rightFlankRow);

        if (leftEnemy  != null) leftEnemy.takeDamage(cleaveDamage);
        if (rightEnemy != null) rightEnemy.takeDamage(cleaveDamage);

        if (leftEnemy != null || rightEnemy != null) {
            eventTextSystem.showText("CLEAVE!", EventTextSystem.CLEAVE_COLOR);
        }
    }

EnemyManager.getEnemyAt(int tileColumn, int tileRow): returns the living enemy at
that tile or null. Add this method if it doesn't exist.

Rotation math for flanks: if facing is (dx, dy):
  Left perpendicular  = (-dy, dx)   — 90° CCW
  Right perpendicular = (dy, -dx)   — 90° CW
Applied to hit enemy tile (not player tile), so it correctly finds the tiles
beside the target.

F. Berserker's Oath — PASSIVE/ON_KILL (legendary, melee only)
──────────────────────────────────────────────
Kill-streak mechanic: each consecutive turn where the player kills at least one
enemy with this weapon adds a stack. On a turn with no kill, reset to 0.
Each stack gives +BERSERKER_DAMAGE_PER_STACK% damage and +BERSERKER_HP_TICK HP.

State: berserkerStacks (int) lives on the weapon or on AbilityResolver
  (prefer weapon to keep state co-located).

In Weapon.java, add:
    private int berserkerStacks = 0;
    public int  getBerserkerStacks() { return berserkerStacks; }
    public void incrementBerserkerStacks() { berserkerStacks = Math.min(berserkerStacks + 1, GameBalance.BERSERKER_MAX_STACKS); }
    public void resetBerserkerStacks()    { berserkerStacks = 0; }

In AbilityResolver.onKill() (only if BERSERKERS_OATH present):
    if (weapon.hasAbility(WeaponAbility.BERSERKERS_OATH) && weapon.isMelee()) {
        weapon.incrementBerserkerStacks();
        int stacks = weapon.getBerserkerStacks();
        int hpTick = stacks * GameBalance.BERSERKER_HP_TICK_PER_STACK;
        player.heal(hpTick);
        // Damage bonus is applied as a temp buff valid for the next fire:
        float damageBuff = stacks * GameBalance.BERSERKER_DAMAGE_PER_STACK;
        playerStats.applyTempDamageBuff(damageBuff, 1);
        if (stacks == GameBalance.BERSERKER_MAX_STACKS) {
            eventTextSystem.showText("BERSERK!", EventTextSystem.BERSERK_COLOR);
        }
    }

Stack reset: on a player turn where no kill occurred with this weapon,
resetBerserkerStacks(). The cleanest place to trigger this is at the START of
each fire() call: save "hadKillThisFire = false", then after fire completes,
if !hadKillThisFire && hasBerserkersOath → reset.
Alternatively, use the TickEventBus: subscribe to each tick and check a
"killedThisTurn" flag that is set by onKill.


IMPLEMENTATION NOTES
====================
- Cleave uses integer perpendicular rotation: left = (-dy, dx), right = (dy, -dx).
  This is exact for cardinal directions — no trig needed.
- Cleave damage bypasses Armor Pierce (it is a secondary splash, not a primary hit).
  However, it DOES benefit from Executioner if the flanked enemy is low HP.
  AbilityResolver.onHit() is called recursively for each cleave target: call
  onHit(weapon, leftEnemy, cleaveDamage, ...) so all ON_HIT abilities chain.
  Guard against infinite recursion: Cleave should not re-trigger on the recursive
  onHit calls (use a boolean cleaveInProgress flag in the resolver or a depth counter).
- Salvage Strike drops at the KILLED enemy's tile, not at the player's tile.
  Use the enemy's last position before removing it from EnemyManager.
- Scholar's Edge stacks with any existing XP bonuses from PlayerStats attributes
  (additive). The bonus XP counts toward level-up progress.
- Berserker's Oath is legendary-only and melee-only, so it will only appear
  together with BERSERKERS_OATH in the WeaponAbility enum (legendaryOnly=true).
  The stack counter persists for the whole run (across levels) since the weapon
  persists; it resets on weapon switch or weapon drop.
- Run `./gradlew build` after implementation.
