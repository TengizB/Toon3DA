OVERVIEW
========
The per-run growth spine. Killing enemies grants XP scaled by enemy type; a thin
XP bar and a LEVEL number live in the HUD. On level-up the world pauses and the
marine "jacks a Combat Stim", choosing ONE of THREE randomly drawn perk cards
(Doom RPG boon-card moment crossed with Hades). Max player level is 20; the XP
curve stretches as the player climbs. This is the concrete, ship-first leveling
loop that the broader boon-pool docs describe abstractly.

This document OWNS: the XP-per-type table, the closed-form XP curve, the level
cap, the HUD bar/badge, the 18-perk pool, and the card-draw rules. It does NOT
re-invent the stats data structure (see roguelike_order_12) or enemy scaling.

GAMEPLAY LOOP
=============
EARN XP (passive, every kill):
1. Enemy HP reaches 0 (any source: weapon, melee, hazard, status effect tick).
2. EnemyManager's death path calls progressionManager.awardExperience(
   enemy.getXpReward()) BEFORE the enemy is dropped from the list.
3. xpReward is the BASE value for that enemy type (NOT depth-scaled — keeps the
   curve meaningful; deeper floors give the same XP but enemies are tougher).
4. A "+N XP" entry posts to the kill feed. The HUD XP bar advances.

LEVEL-UP TRIGGER (turn-gated, never mid-animation):
1. After the turn's damage/death resolution completes, ProgressionManager checks
   experience >= experienceForNextLevel(currentLevel) AND currentLevel < 20.
2. If yes, pendingLevelUps += 1 (a COUNT — a chain explosion dumping a big XP
   lump can queue several). It does NOT interrupt the in-flight turn.
3. World opens the perk overlay only when PlayerController is IDLE and no
   fade/transition is running — the choice never appears mid-slide.

THE PERK CHOICE (the decision):
1. World enters phase LEVEL_UP. The 3D view dims; three perk cards render. The
   turn engine is frozen; this costs NO turn (same tile, same facing on resume).
2. BoonPool.drawThree() picks three DISTINCT perks (see DRAW RULES below).
3. Player presses 1 / 2 / 3 (or LEFT/RIGHT + ENTER) to select.
   - Player presses key N -> perk N's apply(player, runState) hook runs (mutates
     a stat, sets a flag, or grants an item).
   - currentLevel += 1; experience -= experienceForNextLevel(oldLevel) (carry
     overflow); pendingLevelUps -= 1; experienceForNextLevel recached.
4. If pendingLevelUps > 0, present the next card screen back-to-back. Else the
   overlay slides out; World returns to PLAYING.
5. If currentLevel == 20, the bar shows "MAX" and no further level-ups queue;
   surplus XP is discarded.

PLAYER EXPERIENCE
=================
- Every kill ticks a bar the player watches fill. The level-up is a reward beat
  that breaks combat tension and hands the player agency.
- The three-card draw is a real decision under run state: bleeding out on a deep
  floor -> take a Vitality/heal perk; building a glass cannon -> stack damage.
  Over a run these picks compound into a recognizable lean (tank vs glass cannon
  vs status-spec), satisfying the run-identity pillar.
- A capped level (20) plus a stretching curve means leveling slows down deep in
  a run, so each late perk feels earned and the player must rely on tactics, not
  grinding, in the final floors.

XP CURVE (closed form, in GameMath with derivation comment):
    experienceForNextLevel(level) =
        round( XP_CURVE_BASE * pow(level, XP_CURVE_EXPONENT) )
  level = current level (1..19); result = XP to reach level+1. Cache it; pow
  runs once per level-up, never per frame. Clamp level >= 1. No threshold above
  level 19 (level 20 is the cap).

  With XP_CURVE_BASE = 100, XP_CURVE_EXPONENT = 1.32 the user's intent (100 for
  L2, ~250 for L3, scaling up) is matched closely:
    L1->2: 100   L2->3: 250   L3->4: 432   L4->5: 626   L5->6: 838
    L10->11: 2105   L15->16: 3680   L19->20: 5071
  (Tune BASE/EXPONENT against per-floor XP budget. To hit EXACTLY 100/250 use a
  small lookup table override for the first few levels, then fall to the curve.)

PERK POOL (18 perks — id : name : rarity : effect : maxStacks)
==============================================================
Effects reference roguelike_order_12 stats (Strength/Agility/Toughness/
Marksmanship) and the existing weaponDamageMultiplier. Where a perk touches a
system from another doc, that doc owns the underlying field.

COMMON (weight 70 — bread-and-butter survivability/offense):
1.  vitality_boost   : "VITALITY"      : +20 max HP, +20 current HP        : x5
2.  plating          : "PLATING"       : +15 max armor, +15 current armor  : x5
3.  honed_edge       : "HONED EDGE"    : weaponDamageMultiplier *= 1.10     : x5
4.  iron_skin        : "IRON SKIN"     : +1 Toughness (damage reduction)    : x10 (stat cap gates)
5.  quick_step       : "QUICK STEP"    : +1 Agility (move/rotate speed)     : x10
6.  brawn            : "BRAWN"         : +1 Strength (melee damage)         : x10
7.  marksman_focus   : "MARKSMAN FOCUS": +1 Marksmanship (ranged dmg/acc)   : x10

RARE (weight 25 — directional build pieces):
8.  wide_eyes        : "WIDE EYES"     : +10 deg FOV (default 90 -> +10/pick); cap 120 : x3
9.  field_surgeon    : "FIELD SURGEON" : medkits/stims heal +50%            : x2
10. ammo_hoarder     : "AMMO HOARDER"  : enemy ammo drops +1; +1 max per weapon : x2
11. adrenal_pump     : "ADRENAL PUMP"  : free extra action the turn after a kill : x1
12. bulwark          : "BULWARK"       : armor absorbs +25% of incoming damage : x2
13. swift_reload     : "SWIFT RELOAD"  : 25% chance a reload/pump costs no turn : x2
14. pyromaniac       : "PYROMANIAC"    : take half FIRE damage; your fire/explosion +25% : x1

EPIC (weight 5 — run-defining):
15. berserker        : "BERSERKER"     : melee damage +100% while HP < 30%   : x1
16. second_wind      : "SECOND WIND"   : once per floor, lethal hit leaves you at 1 HP instead : x1
17. overcharge       : "OVERCHARGE"    : weaponDamageMultiplier *= 1.30 but -20 max HP : x1
18. executioner      : "EXECUTIONER"   : enemies below 15% HP die instantly when hit : x1

DRAW RULES (PerkPool.drawThree)
-------------------------------
1. Eligible = all perks not at maxStacks for this run. Track per-perk takenCount
   on RunState; remove when takenCount == maxStacks.
2. Weighted sample WITHOUT replacement by rarity (COMMON:RARE:EPIC = 70:25:5),
   seeded by the run seed (procedural-generation pillar; reproducible).
3. Anti-brick guarantee: at least one COMMON card among the three (so the player
   always has a safe survivability/offense pick). Re-roll the third slot if all
   three rolled RARE/EPIC.
4. Pre-allocate the 3-element result array in PerkPool's constructor; NO
   allocation when the overlay opens.
5. If fewer than 3 eligible perks remain (very late run), pad with the highest-
   stack-remaining COMMON stat perks.

BALANCE NOTES
=============
- First promotion at 100 XP (~a couple of kills) teaches the system in room 1.
- XP is FLAT (not depth-scaled) so the player levels SLOWER relative to threat
  the deeper they push — classic roguelike pressure. Add XP_DEPTH_BONUS only if
  deep runs feel under-leveled.
- Vitality/Plating add headroom + current amount, NOT a full heal — keeps the
  pick honest against attrition (field_surgeon and a future heal-perk are the
  panic options).
- EPIC perks are run-defining and intentionally rare (5% weight, mostly x1
  stacks). overcharge and second_wind are double-edged per the meaningful-choice
  pillar.
- Level cap 20 + stretching curve prevents infinite power scaling and keeps deep
  floors tactical, not numeric.

============
1. STATS (roguelike_order_12): the stat-bump perks (iron_skin, quick_step,

   that doc owns the stat fields and caps. This doc only references them.

   doc's GameBalance table mirrors them. Boss kills grant a large lump.
3. STATUS EFFECTS (roguelike_order_14): pyromaniac halves FIRE status damage to
   the player; a kill via a status tick still routes through awardExperience.
4. MELEE (roguelike_order_15): berserker and brawn boost melee damage; a melee
   kill grants XP through the same death path.
5. ENEMY SCALING (xp-level-progression-system.txt): depth scaling is owned there;
   XP stays flat here.
6. WEAPONS (all weapon docs): honed_edge/overcharge scale weaponDamageMultiplier,
   read once at fire time. swift_reload/ammo_hoarder hook weapon turn-cost/ammo.
7. HUD (procedural-hud / scanline-crt): XP bar + level badge join left-panel
   vitals; overlay reuses CRT styling.
