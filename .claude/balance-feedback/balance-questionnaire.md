# Balance Feedback Questionnaire

Purpose: turn "the balance doesn't feel right" into concrete, observable complaints
and targets, so the next balance idea file tunes toward what the OWNER wants — not
toward bands Claude invented.

How to answer:
- Write under each `Answer:` line. Short answers are fine; "don't know" is a valid answer.
- Describe what you SAW and FELT, not what number you think should change.
  ("I ran out of shells on every elite floor" beats "raise AMMO_BOX_SHELLS".)
- Specific moments are gold: depth, floor type, which enemies, what happened.
- Skip any question you can't answer — then say so, so it isn't mistaken for "no problem".

When done, ask Claude to write the balance-tuning idea file from these answers.
