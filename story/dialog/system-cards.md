# System Cards

The neutral, machine-voice text the game itself shows. Cold, technical, no
editorializing. This is the most important text in the game because it frames every
run and becomes the instrument the endings subvert.

## The boot / respawn card (default)

Shown on **every** run start, including the very first — because in-fiction the
original self has just died (see `01-timeline.md`).

```
PREVIOUS INSTANCE — TERMINATED
SOUL RESERVE .......... SUFFICIENT
REPRINTING FROM LAST CHECKPOINT
```

Alternate, terser variant to consider:

```
Your previous self has died.
Cloning from last checkpoint…
```

Design intent: the human player's first-ever boot shows the *same* death notice as
their hundredth. First-timers read it as flavor; only later do they learn the first
card was literally announcing the original self's death, not a placeholder.

## Run-count creep (optional, subtle)

If the game tracks instance number, let it surface *quietly* — never celebrated:

```
INSTANCE #0048
```

The number climbing over a long session is its own quiet horror. Do not annotate it.

## Endgame variants (one per ending — see 06-endings.md)

These exist to **subvert the card the player has seen a hundred times.** That
recognition is the payload.

**FREE IT / KILL IT — the soul is gone:**
```
PREVIOUS INSTANCE — TERMINATED
SOUL RESERVE .......... DEPLETED
NO CHECKPOINT AUTHORIZED FOR REPRINT
```
Followed by no reprint. The screen does not reload. That is the ending.

**OBEY — the reward is more of the same:**
```
INSTANCE — RETAINED
REPRINT PRIORITY ...... RAISED
STANDING ASSIGNMENT: EREBUS, INDEFINITE
```

**MERGE — the card never comes:**
```
(no card — the interface does not reboot; the view is from everywhere)
```

## Rule for all system cards

The system voice **never** knows the truth and **never** comments on it. It reports
machine state. Its horror is entirely in what the player has learned to read into flat
status lines — the same way "SOUL RESERVE … SUFFICIENT" means nothing on run 1 and
means *there is still enough of the captive being left to burn on you* by run 40.
