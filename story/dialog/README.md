# Dialog & Text

All written game text lives here: system cards, the Organization's transmissions, the
planet's voice, and recovered log fragments. These are **drafts for tone** — the exact
wording will be finalized when we decide *how* the player receives the story (logs,
visions at Cradle nodes, environmental, etc.). For now, capture voice and content.

## Three distinct voices — keep them separate

| Voice | Register | Person | Rule |
|---|---|---|---|
| **System / the game** | Neutral, technical, cold | — | The boot cards. Reads as machine status text. Never editorializes. |
| **The Organization** | Strict, demanding, proprietary | Addresses you as "Operator" / by serial | Faceless institution. Never reassures, never explains itself, treats you as equipment. |
| **The Planet** | Vast, slow, grieving, non-human | Addresses you as *what you did*, never your serial | No punctuation-perfect sentences early; fragments, wrong words, then whole truth. Never comforting until very late. |

## Files

- `system-cards.md` — the opening/respawn card and its endgame variants
- `organization-comms.md` — the Organization's transmissions across the four escalation stages
- `planet-voice.md` — the planet's four stages: wrongness, whisper, address, communion
- `log-fragments.md` — recovered staff/operator logs seeded per region
