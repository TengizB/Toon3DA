# REGION WALL ATLAS (generated-wall-art order 2): every wall, door and column face of a floor comes from the
#  floor's region wall set - render/tilesetgfx/RegionWallAtlas, built by World with the floor and disposed with
#  it. WallRenderer.setRegionWallAtlas(atlas, floorSeed) resolves each char to face indices ONCE per level
#  (wall symbol -> WallSlotTable slot -> the set's face ids -> atlas indices; doors d R Y B; the floor's
#  column), so the hot per-column path reads plain int arrays. The old per-symbol textures, generators and
#  EnvironmentTextureSet wall role are DELETED. The contract is docs/wall-art-creation-guide.txt section 13.
#  Below, "wallTexture" means "the region atlas" and texColumn/srcY are offsets inside the struck face.

# WallRenderer implementation details — reference for agents extending the renderer.

=== PER-FRAME PIPELINE (historic outline: steps 1-2 are now FloorCeilingRenderer's own GPU pass) ===

1. Ceiling rect (top half, dark navy 0.1,0.1,0.2) via 1×1 white pixel texture tinted.
2. Floor rect (bottom half, dark gray 0.12,0.12,0.12) — same approach.
3. [Auto batch flush here: whitePixelTexture → wallTexture]
4. For each screen column: cast DDA ray → perpWallDistance → texColumn → draw 1px-wide wall stripe.
   All column draws (1280 at HD, 1920 at FULL HD) accumulated in one batch call.

batch.draw per column (region atlas):
  face   = wallFaceIndices[start[char] + GameMath.wallVariantIndex(column, row, side, floorSeed, count)]
  mip    = GameMath.wallMipLevel(lineHeight, 256, WALL_MIP_BIAS, 2);   size = 256 >> mip
  batch.draw(atlas,
             screenColumn * columnWidth, drawBottom,
             columnWidth, drawTop - drawBottom,
             faceX(mip) + texColumn, faceY(mip) + clipSrcY, 1, clipSrcHeight,   // srcX, srcY, srcW, srcH
             false, false);                     // no flip needed
  faceY = the face's TOP row in the atlas; LibGDX Y-up maps image rows top-down without manual flip.
  side: 0 W / 1 E / 2 S / 3 N face of the struck tile (from the DDA step), so variants are stable per face.
GLOW (PHASE 4, after the muzzle-light pass): the glow atlas at the same face rect / mip (an animated face at
  mip 0 uses its current frame's rect), NORMAL blend, colour (1,1,1, alpha) - ungraded; alpha =
  GameMath.wallGlowDistanceAlpha(distance, 10, 20, 0.6) x level.getLightMultiplier() (BLACKOUT). A column
  with a door panel draws only the panel's glow.

Shading: batch.setColor(red, green, blue, 1f) before each draw — embeds tint in vertex data, no flush.
  The scalar shade (falloff × face × tile brightness, clamped) is GRADED per column by the floor's
  lighting mood (visual-identity-order-1): channel = clamp01(shade × tint), tint from
  AtmosphereGrade.evaluateInto(mood, perpWallDistance, GRADE_STRENGTH_ENVIRONMENT, column.gradeScratch)
  — the static, thread-safe variant, because columns run on worker threads. The red-alert boost/dampen
  is applied after the grade. Walls, door panels and columns all take it. See docs/art-direction.txt.
  MUZZLE LIGHT (visual-identity-order-2): NOT part of the clamped multiplier above. Workers compute the
  per-column light add (AtmosphereGrade.lightAddInto into gradeScratch[3..5], zero unless a shot was fired
  in the last 0.10 s) and store it on the column result. render() then runs an extra PHASE 3 after the
  base draws: the same column slices re-drawn with additive blending (GL_SRC_ALPHA, GL_ONE), colour =
  light add, skipped entirely at intensity 0, blend func switched exactly twice. A column with a door
  panel lights the panel only. See docs/art-direction.txt section 11.

BASE-PASS COST CUTS (render-performance-full-hd, both pixel-identical):
  R16 OPAQUE BASE PASS - the region atlas is RGB by contract (guide section 12), so levelSurfacesOpaque is
      always true and the base pass runs with batch.disableBlending() (re-enabled before Phase 3).
  R18 COLUMN MERGE - neighbouring columns whose surface slice is EXACTLY equal (texture, texColumn, srcY,
      srcHeight, drawBottom, drawTop, colour; no door panel) are submitted as one wider quad sampling the same
      1-texel source column (isSameSurfaceSlice). Built because the base-pass submission measured ~31% (median)
      of the CPU wall pass. With the region atlas the key (texture, absolute srcX, srcY, height) implies the
      face, variant and mip; merges still happen within a face slice.
  The muzzle-light Phase 3 still draws per column.

Performance:
  Ceiling + floor  → drawn by FloorCeilingRenderer (its own batch), not here
  Base pass        → 1 bind (the region atlas: walls + doors + columns)
  Glow pass        → 1 bind (the glow atlas)
  Draw calls do not grow with the number of distinct walls on the floor.

=== RESOLUTION CONTROL ===

The ray-column count is RUNTIME state, set by the player's RESOLUTION setting (settings screen
and codex strip; persisted as `story.setting.render.resolution`). `util/RenderResolution`:

  HD       1280 columns, columnWidth 1.0 world unit,   180 floor/ceiling rows  (lighter tier)
  FULL_HD  1920 columns, columnWidth 0.667 world unit, 540 floor/ceiling rows  (default, quality tier)
  (The floor/ceiling is GPU-drawn - perspective tile quads + a far span band, sampled at native resolution;
   the row count only fixes its per-row tables. See docs/art-direction.txt -> FLOOR / CEILING PIPELINE.)

World units stay 1280x720 — only the 3D view's internal resolution changes. HUD, text and menus
are already drawn at the device's native pixels.

WallRenderer is the SINGLE authority: setRenderResolution(RenderResolution),
getProjectionColumnCount(), getColumnWidth(). World.applyStoryAccessibilitySettings() pushes the
setting into it and into FloorCeilingRenderer.setRenderResolution() at startup, on every knob
tap and after every floor rebuild (rebuildForLevel builds fresh renderers: WallRenderer and the
billboard renderers start at HD, FloorCeilingRenderer at RenderResolution.DEFAULT; the push then sets
the player's tier, a no-op where it already matches).
Arrays and SpriteBatches are sized for RenderConstants.RENDER_RESOLUTION_MAX_COLUMNS, so a
change never allocates on the render path; FloorCeilingRenderer only rebuilds its row tables
(no GPU resource depends on the tier), and only when the tier actually changes.

COLUMN SPACE vs WORLD X — the rule every billboard renderer must follow:
  - GameMath.spriteScreenColumnCenter(..., projectionColumnCount) returns a COLUMN.
  - A width computed in world units (e.g. from spriteScreenHeight) must be divided by
    columnWidth before it is used as a column span in a per-column z-tested loop.
  - Anything drawn with a single world-space call (health bars, intent icons, particles,
    ShapeRenderer rects, text) must convert: worldX = column * columnWidth. Z-buffer lookups
    use the column index.
  At HD columnWidth == 1, so mixing the two is invisible there and breaks only at FULL HD.
  ImpactEffectRenderer/System project against Constants.WORLD_WIDTH, i.e. straight to world X.

A new tier (e.g. a retro 320-column look) is one RenderResolution constant plus its
RenderConstants number and label string ids.

=== Z-BUFFER ===

perpWallDistance stored per column in pre-allocated float[] zBuffer.
Retrieve: getZBufferAt(int screenColumn).
Required for sprite rendering: only draw sprite pixel at column c if depth < zBuffer[c].

=== GAMEMATH METHODS — 3D PROJECTION ===

cameraPlaneX(dirY, scale)              → −dirY × scale
cameraPlaneY(dirX, scale)              → +dirX × scale
cameraPlaneParameter(col, width)       → 1 − 2×col/width  (Y-up column mapping)
cameraPlaneRayDirectionX/Y(...)        → dir + plane × cameraParam
perpWallDistance(sideDist, deltaDist)  → sideDist − deltaDist
wallStripeHeight(screenH, perpDist)    → screenH / perpDist
wallStripeDrawBottom/Top(screenH, lineH) → centre stripe on horizon
wallShade(perpDist, falloff)           → 1 / (1 + d² × falloff)
wallHitPosition(...)                   → fractional hit position along wall face
wallHitPositionMirrored(...)           → mirror correction for opposite-side reads
textureColumn(wallHitU, width)         → (int)(u × width) clamped to [0, width−1]
wallTextureClipSrcY(...)               → texel row start for close-wall clipping
wallTextureClipSrcHeight(...)          → texel row count for close-wall clipping

=== EXTENDING THE RENDERER ===

Change wall texture:
  Replace assets/textures/wall.png, update Constants.WALL_TEXTURE_PATH.
  Sizes 64–1024 work without code changes (width/height read at load time).

Multiple wall types:
  Extend level.getCell() → pick Texture per char in render loop.
  Switching textures causes flush per switch — pre-sort columns by texture if perf matters.

Add floor/ceiling textures:
  Replace solid-colour rects with per-pixel row casting (Lodev floor casting).
  Apply Y-up cameraParameter sign flip.

Add sprites:
  Sort by distance. For each sprite column: check depth < zBuffer[col] before drawing.

Change FOV at runtime:
  Set player.fieldOfViewRadians — planeScale recomputed each frame in WallRenderer.

Add new wall math:
  Put in GameMath with formula/derivation/edge-cases comment block.
  Never inline wall-projection math in WallRenderer.
