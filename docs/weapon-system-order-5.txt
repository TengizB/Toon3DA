IMPLEMENTED: weapon-system-order-5 — Weapon Sustain Abilities
==============================================================

Adds six sustain and defensive weapon abilities to the fire pipeline.
All resolve through AbilityResolver hooks already wired in Weapon.fire().

ABILITIES
---------
LIFESTEAL (ON_HIT)
  Heals player for a fraction of base damage dealt each hit.
  Shows event text only when heal >= LIFESTEAL_TEXT_THRESHOLD (5 HP) to avoid spam.
  Magnitude pre-scaled by WeaponRoller; resolver reads it via weapon.abilityMagnitude().

HEMORRHAGE_HARVEST (ON_KILL)
  Heals player for a fixed HP amount on confirmed kill.
  Always shows green "+N HP" event text.

VAMPIRIC_CRIT (ON_CRIT)
  Heals player for a fixed HP amount whenever a critical hit lands.
  Shows green "CRIT HEAL +N" event text.
  Fires only after CRITICAL_STRIKE already confirmed the crit in onHit().

ADRENAL_SURGE (ON_KILL)
  Rolls the pre-scaled proc chance on kill.
  On success: stores a one-shot damage bonus in PlayerStats via applyAdrenalSurge().
  AbilityResolver.onFire() polls and consumes the buff (pollAdrenalSurgeMultiplier()).
  "Next attack only" semantics — consume-on-read, no tick countdown needed.
  Shows white "SURGE!" event text when proc fires.

BULWARK_ROUNDS (ON_RELOAD)
  Grants temporary armor on reload completion (only when rounds were chambered).
  Stored in PlayerStats as a turn-limited pool (up to BULWARK_TEMP_ARMOR_SLOTS = 4 stacks).
  Consumed before regular armor in Player.applyDamage() and Player.applyDoTDamage().
  Decremented each player-action turn via a TickSubscriber registered in World.buildLevelDependentResources().
  Shows white "BULWARK +N" event text.

SECOND_WIND (PASSIVE)
  Checked in onFire() each activation — no stored state.
  If player HP fraction <= SECOND_WIND_HP_THRESHOLD (30%), multiplies fireCycleMultiplier.
  Stacks multiplicatively with ADRENAL_SURGE if both are active.

ARCHITECTURE NOTES
------------------
- fireCycleMultiplier is a transient Weapon field reset at fire() start and applied in
  damageAtDistance(). All weapon subclasses using damageAtDistance() pick it up automatically.
- Adrenal Surge uses consume-on-read instead of tick countdown to avoid timing issues
  (kill and tick fire in the same action turn, which would expire a duration=1 buff immediately).
- Bulwark temp armor uses tick countdown (duration=3) so the off-by-one is not significant.
- String concatenation in event text ("+N HP") happens at action time, not render time — safe.
- NOTE: Weapon subclasses that do NOT call setLastHitEnemy() in marchShot() (e.g. Shotgun
  in its current state) will not trigger onHit/onCrit/onKill callbacks, so LIFESTEAL,
  VAMPIRIC_CRIT, HEMORRHAGE_HARVEST, and ADRENAL_SURGE won't fire for those weapons until
  setLastHitEnemy() is wired in. SECOND_WIND and BULWARK_ROUNDS are unaffected.
