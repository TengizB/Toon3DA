TILE SYMBOL REFERENCE
=====================
Single source of truth for every character used in level .txt files.

STRICT RULE: Every time a new symbol is introduced anywhere in the codebase
(Level.java, LevelLoader.java, LevelGenerator.java, WallRenderer.java, or any
other class that reads tile characters), this file MUST be updated in the same
commit. No symbol may be used in a level file or recognised by game code unless
it appears here first.

Authority class: Level.java — isWall(), isColumn(), isPropSolid(), isPropDecal(),
and the pickup/door/special checks are the single runtime source of truth.
When this file and the code disagree, fix the code to match this file.

ADDING A NEW SYMBOL — CHECKLIST
--------------------------------
1. Pick an unused symbol from the free list above.
2. Add it to this file (correct section, with description and notes).
3. Add it to Level.java in the appropriate method: isWall(), isPropSolid(),
   isPropDecal(), or a new dedicated check.
4. Add texture/sprite lookup in WallRenderer.java or PropRenderer.java.
5. Add any Constants entries (texture path, height multiplier, etc.).
6. Update docs if the symbol affects level generation (LevelGenerator.java).
7. Update the symbol count in SYMBOL BUDGET above.
8. Commit all of the above together — never add a symbol in code without
   updating this file in the same commit.
